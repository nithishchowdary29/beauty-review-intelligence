# Publish the project and submit each week

The files are prepared. A live repository URL exists only after publishing
to your GitHub account. Do not submit a placeholder URL.

## Simple browser method

1. Download and extract the project ZIP on your laptop.
2. Open https://github.com and sign in to your account.
3. Click the **+** near the top right, then **New repository**.
4. Enter `beauty-review-intelligence` as the repository name.
5. Description: `Beauty and wellness review classification with Python — six week internship project using clearly labelled synthetic data.`
6. Choose **Public** if the evaluator needs access without signing in. Review
   the files first. This project includes your name and synthetic records.
7. Click **Create repository**. On its quick setup page choose **uploading an
   existing file**. If a README was created, choose **Add file > Upload files**.
8. Open the extracted `beauty-review-intelligence` folder on your laptop.
   Drag its CONTENTS into the GitHub upload area, preserving subfolders.
   Do not upload only the ZIP. Do not upload `helpers`, `.venv`, or QA renders.
9. Enter `Add six week beauty review data science project` as the commit
   message, then click **Commit changes**.
10. Confirm that GitHub displays `README.md`, `src`, `data`, `outputs`, and
    `reports`. Open `src/run_project.py` to verify that the code is visible.
11. Copy the address of the repository homepage from the browser address bar.
    Use this SAME real URL in all six weekly forms unless your evaluator
    explicitly requests a separate repository for each week.

If browser upload does not preserve folders, use GitHub Desktop: **File >
Add local repository > Choose** the project folder; select **create a
repository here** if prompted, commit the files, then **Publish repository**.
Check the public/private setting before publishing.

## Submit the internship reports

For Week 1 upload `Week_01_Problem_Definition.docx`. Repeat for Weeks 2 to 6
using the corresponding file. Open `Submission_Descriptions.docx`, copy the
matching week's description, and paste it into that week's description field.
Every description exceeds 200 words. Paste the real repository URL. Review
the preview and click Submit yourself. Keep confirmation screenshots locally
if needed. No internship-portal submission has been performed for you.

## Before submitting

Read each report so you can explain the label, the use of synthetic data,
the cleaning choices and the precision/recall tradeoff. Run the code if
possible. Do not describe these results as analysis of actual customers.
Do not claim 30–35 hours per week solely because that is the suggested
workload. If the provider requires real data instead of the simulation
allowed in the supplied task, request its clarification before submitting.
